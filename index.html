About This Project

A modern, responsive weather forecast application built with vanilla JavaScript, TailwindCSS, and the WeatherAPI. Features include real-time weather updates, 3-day forecasts, geolocation support, and text-to-speech capabilities.

JavaScript ES6+ TailwindCSS WeatherAPI Geolocation API Web Speech API LocalStorage

Data provided by WeatherAPI.com
