## 🐛 Troubleshooting

### Issue: Improved version not working

**Check**:
1. Is `app.js` in the same folder?
2. Are images in `./images/` folder?
3. Is API key still valid?
4. Any console errors? (F12 → Console)

### Issue: Geolocation not working

**Solution**:
- Use HTTPS or localhost
- Allow location permission in browser
- Try different browser

### Issue: Voice not working

**Solution**:
- Works best in Chrome/Edge
- Check volume/mute
- Click speak button after page loads
